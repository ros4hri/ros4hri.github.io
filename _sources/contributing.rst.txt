Contributing to ROS4HRI
=======================

ROS4HRI is an open-source project and we welcome contributions from the community!

Whether you want to report a bug, suggest a new feature, or contribute code, there are several ways to get involved.

Zulip Chat
----------

The best way to get in touch with the community and discuss ROS4HRI is through our Zulip chat:

**Join us on Zulip** by following `this invitation link <https://ros4hri.zulipchat.com/join/2cg6fiwimt5wf6g5lawhdosx/>`_.

GitHub Discussions
------------------

You can also use GitHub Discussions to propose new ideas or ask questions:

`ROS4HRI GitHub Discussions <https://github.com/orgs/ros4hri/discussions>`_

Contributing Code
-----------------

If you want to contribute code, please check the individual repositories in the `ROS4HRI GitHub organization <https://github.com/ros4hri>`_.
Most repositories follow the standard ROS 2 contribution guidelines.

Improving Documentation
-----------------------

Found a typo or want to improve this documentation? You can submit a pull request to the `ros4hri.github.io <https://github.com/ros4hri/ros4hri.github.io>`_ repository.
